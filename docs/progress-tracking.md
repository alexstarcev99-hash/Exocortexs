# Система отслеживания прогресса

## Ключевые метрики развития

### 1. Количественные метрики

#### Объем практики
```
Метрика: Часы в деле (deliberate practice)
Целевое значение: 10,000 часов для мастерства (по Малькольму Гладуэллу)
Трекируется: Еженедельно

Примечание: Качество важнее количества — 1 час осознанной практики > 10 часов механического повтора
```

#### Завершённые проекты
```
Метрика: Quantity of shipped projects
Целевое значение: 
  - Уровень 1: 2-3
  - Уровень 2: 5-10
  - Уровень 3: 10-20+
Трекируется: Помесячно
```

#### Созданный контент
```
Метрика: Документы, гайды, уроки
Целевое значение:
  - Уровень 1-2: 0-3
  - Уровень 3: 3-10
  - Уровень 4: 10+
Трекируется: Квартально
```

### 2. Качественные метрики

#### Скорость решения проблем
```
Показатель: Как быстро вы решаете проблемы без посторонней помощи?
  - Уровень 0: Не могу (нужна полная помощь)
  - Уровень 1: Нужны пошаговые инструкции
  - Уровень 2: Анализирую и решаю (30 мин - 2 часа)
  - Уровень 3: Интуитивно вижу решение (5-15 мин)
  - Уровень 4: Вижу решение мгновенно + альтернативы

Целевой переход: 0→1 за 1-3 месяца
```

#### Способность учить других
```
Показатель: Могу ли я научить новичка?
  - Уровень 0-1: Нет, сам еще учусь
  - Уровень 2: Могу поделиться опытом
  - Уровень 3: Могу систематизировать и передать знание
  - Уровень 4: Создал систему обучения, которая работает без меня

Целевой переход: 1→2, затем 2→3
```

#### Адаптивность к новому контексту
```
Показатель: Как я применю мастерство в новом контексте?
  - Уровень 0-1: Не справляюсь, нужно переучиваться
  - Уровень 2: Адаптирую существующие подходы
  - Уровень 3: Вижу основные паттерны и переношу их
  - Уровень 4: Создаю новые подходы под новый контекст

Целевой переход: Важен на 2→3 и 3→4
```

## Уровень осознанности

## Диагностический цикл

### Этап 1: Диагностика (Неделя 1-2)
- Честно оценить текущий уровень
- Выявить сильные стороны и пробелы
- Зафиксировать точку старта

### Этап 2: Планирование (Неделя 2-3)
- Выбрать одно направление развития
- Определить целевой уровень (обычно +1 уровень)
- Разработать план действий (3-6 месяцев)

### Этап 3: Практика (Неделя 3+)
- Еженедельная рефлексия (30-60 мин)
- Документирование прогресса
- Корректировка плана при необходимости

### Этап 4: Переход (Месяц 3-6)
- Внешняя валидация (обратная связь от других)
- Достижение метрик для нового уровня
- Осознанное признание изменения

## Инструменты для отслеживания

### Основной трекер
- Файл: `/progress/[направление]/[период].md`
- Обновляется: Еженедельно
- Архивируется: Ежемесячно

### Аналитика
- Тренды часов практики: месячные
- Количество завершенных проектов: квартальные
- Смена уровней: годовые

### Обратная связь
- Регулярные интервью с наставниками/коллегами
- Самонаблюдение и рефлексия
- Метрики от конкретных проектов

## Признаки реального прогресса

✓ Решаю задачи быстрее (не потому что легче, а потому что вижу решение)
✓ Делаю меньше ошибок (или ошибки становятся более сложными)
✓ Могу объяснить, почему что-то работает
✓ Другие просят совета
✓ Начинаю видеть паттерны, которые не видел раньше
✓ Появляется интуиция
✓ Возрастает самостоятельность

## Частые ловушки

❌ **Самообман уровня** — самооценка выше реальности
  → Решение: регулярная внешняя валидация

❌ **Плато» — нет видимого прогресса
  → Решение: изменить форму практики, усложнить задачи

❌ **Выгорание** — слишком быстрый темп
  → Решение: замедлиться, вернуться к основам, восстановиться

❌ **Отвлечение на новое** — начинаю новое направление, не доразвив старое
  → Решение: финишировать уровень, затем переходить
