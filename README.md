# Системное саморазвитие

**Контекст:** СР | **Версия:** 1.0 | **Статус:** Активное прохождение

## Описание

Структурированный курс по личному развитию и достижению мастерства. Система построена на:
- **Диагностике уровней** (шкала 0-4 — от новичка до эксперта)
- **Траекториях развития** — индивидуальные пути обучения для каждого уровня
- **Метриках прогресса** — объективное отслеживание продвижения
- **Ритме развития** — дисциплина, постоянство, адаптация

## Структура курса

```
/docs              — основные материалы и теория
/inbox             — входящие заметки, захваты знаний
/levels            — описание уровней мастерства 0-4
/trajectories      — пути развития по разным направлениям
/progress          — отслеживание прогресса и метрик
```

## Цели курса

1. **Диагностировать** текущий уровень мастерства
2. **Выстроить** четкую траекторию развития
3. **Установить** ритм обучения и практики
4. **Измерять** прогресс объективно

## Начальные условия (август 2026)

- **Заинтересованность:** Высокая, структурированная
- **Опыт:** Наличие фреймворков и систематизированных практик
- **Цель:** Интегрировать саморазвитие в операционную систему жизни
