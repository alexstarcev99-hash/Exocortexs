## Вводные для выбора методов

- Точные суммы и ставки по каждому долгу (микрозаймы/коммуналка) не разобраны - известна только общая сумма (до 250т руб). Само это отсутствие детализации - проявление разрыва по пункту 1 (прозрачность): даже базовый инвентарь долга не сделан.
- Тип дохода: стабильный оклад (предсказуемый), не проектный/нерегулярный. Это упрощает построение плана - база для бюджета предсказуема.
